# Banking_operations_widget

Банковский виджет для личного кабинета клиента.
Фильтрации, сортировки банковских операций и прочее.
Статус проекта: в разработке 


## Использование

Клонируйте репозиторий по SSH-ключу.
В терминале перейти в папку, где нужно разместить клонированный проект. 
Ввести команду клонирования:
```bazaar
git@github.com:GregoryS163/Banking_operations_widget.git
```

### Установка зависимостей проекта

Чтобы установить зависимости в клонированном проекте с менеджером зависимостей Poetry,
нужно выполнить команду
```
poetry install
```
Инструмент создаёт виртуальное окружение (если оно не существует) 
и устанавливает зависимости, указанные в файле pyproject.toml.
В проекте есть файл poetry.lock, поэтому будут установлены точно те версии,
которые указаны в нём.
Если такого файла нет, Poetry сначала разрешит зависимости на основе pyproject.toml 
и создаст poetry.lock.
