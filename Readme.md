# Banking_operations_widget

Банковский виджет для личного кабинета клиента.
Статус проекта: в разработке
На текущий момент реализованы модули:
- main с основной логикой проекта
- masks (2 функции)
  * маскировка номера карты
  * маскировка номера счёта
- widget (2 функции)
  * обрабатывает информацию о картах, и о счетах 
    и возвращает информацию с масками номера карты или номера счёта
  * преобразует формат даты
- processing (4 функции)
  * фильтрует транзакции по ключу 'state' ("EXECUTED" or "CANCELED")
  * сортирует транзакции по дате
  * Фильтрует банковские операции по категории операции с помощью строку для поиска
  * Подсчитывает количество операций по категориям операций
- generators (3 функции)
  * Поочерёдно выдает транзакции, 
    где валюта операции соответствует заданной
  * поочерёдно возвращает описание каждой транзакции
  * формирует и поочерёдно выдаёт номера банковских карт в заданном диапазоне
- decorators
  * логирует выполнение функции
- finance_file_reader (2 функции)
  * Читает транзакции из Excel-файла
  * Читает транзакции из csv-файла

### Установка зависимостей проекта

Чтобы установить зависимости в клонированном проекте с менеджером зависимостей Poetry,
нужно выполнить команду
```
poetry install
```
Инструмент создаёт виртуальное окружение (если оно не существует) 
и устанавливает зависимости, указанные в файле pyproject.toml.
В проекте есть файл poetry.lock, поэтому будут установлены точно те версии,
которые указаны в нём.
Если такого файла нет, Poetry сначала разрешит зависимости на основе pyproject.toml 
и создаст poetry.lock.

## Testing the code

Код в проекте тестируется с помощью фреймворка pytest.
Для установки pytest в виртуально окружении выполните команду:
```
poetry add --group dev pytest
```
Покрытие кода тестами (code coverage) на текущий момент 100%.
Проверяется с помощью библиотеки pytest-cov. Для установки выполните команду:
```
poetry add --group dev pytest-cov
```
Проверка:
```
pytest --cov
```
